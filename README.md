ChemNexa 🧪

Explore Molecules. Discover Chemistry.

ChemNexa is a chemistry exploration platform designed to help students explore chemical compounds and molecular information.

Features

- Chemical compound search
- Drug molecule database
- Molecular formula and molecular weight
- Chemical structure visualization
- 3D molecular exploration
- Chemistry learning resources

Technology Stack

- Python
- Streamlit
- PubChem PUG REST API
- RDKit
- 3Dmol.js

Purpose

An educational cheminformatics project for exploring chemical structures and molecular data.
